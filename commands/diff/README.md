# diff

Published version: `cli/diff@0.2.6`. See the release inventory;
[latest.json](../../tests/release/latest.json) records the uploaded coordinates.

Compare files and directories for MoonX.

```sh
moonx cli/diff@0.2.6 [-qsauciwbBZrN] [-U LINES | -C LINES] [--label LABEL] FILE1 FILE2
```

## Supported scope

Produce normal, unified or context differences. One input may be stdin. Exit 0 for equal inputs, 1 for differences and 2 for errors.

Default edit alignment follows GNU's repeated-line anchor heuristic. Sparse
repetitions inside unmatched regions need not produce a globally minimal
script; small-input reconstruction and minimality remain separately tested.

## Argument and exit-status contract

Option values and operands after -- remain literal during alias normalization.

See the [finite diagnostic profile](../../docs/compatibility.md#extensions-and-diagnostics).

## Limitations

- Locale collation and comparing symbolic-link target text are unsupported.
- Large comparisons retain complete inputs in memory.

## Examples

```sh
moonx cli/diff@0.2.6 -u old.txt new.txt
moonx cli/diff@0.2.6 -r old-dir new-dir
```
