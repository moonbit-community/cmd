# grep

Search text using MoonBit regular expressions or fixed strings. The supported
surface includes `-E`, `-F`, `-i`, `-v`, `-n`, `-c`, `-l`, `-L`, `-q`, `-H`,
`-h`, `-x`, `-w`, `-e`, `-f`, and recursive `-r`. Exit statuses follow grep:
0 for a selected line, 1 for no selection, and 2 for an error.
