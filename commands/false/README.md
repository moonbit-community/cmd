# false

Return failure for MoonX.

```sh
moonx cli/false@0.2.3 [ignored command line arguments]
```

## Supported scope

Produce no output and exit 1. Other arguments are ignored, except standalone metadata options.

## Options

| Option | Description |
| --- | --- |
| `--help` / `--version` | Show help / package version. |

## Limitations

- Standalone --help and --version exit 0.

## Examples

```sh
moonx cli/false@0.2.3
```
