# O2-O4 option candidates

Date: 2026-10-25. Existing unpublished candidates: sort/printf 0.2.2, seq
0.2.3, fmt 0.1.2 and expand/unexpand 0.1.3. Shared additions select core
0.8.0. Published coordinates and historical expectations remain unchanged.
This records development evidence before this batch's PR/main acceptance.

Sort reuses its cached keys, sequence IDs, external runs and sixteen-input
merge heap. Stable mode suppresses whole-record fallback; unique retains the
first representative. Random order caches MD5(seed16 || transformed key),
then the effective key, with exact source consumption and option inheritance.
Merge assumes ordered inputs. Ordinary output consumes sources before target
truncation and supports input aliases. Existing streaming merge outputs retain
an explicit identity/error-effects rejection, including unchanged targets.

Seq and printf share pure BigInt representation/rounding and formatting for
the frozen GNU Linux amd64 Extended80 profile. Seq adds one-conversion format
validation and endpoint recovery while preserving its existing default path.
Printf adds hexadecimal floating output and C-byte GNU shell escaping. Its
normalized hexadecimal display differs from seq's libc-style display in this
oracle. Shell quoting is shared with later filter work; no second copy of that
state machine is needed.

Fmt extends its existing paragraph optimizer with first/continuation indents
and prefix matching. Split, crown and tagged precedence, remembered hanging
indentation and unmatched/partial EOF records are preserved. Expand/unexpand
share one parser/cursor for absolute and relative tab grids; the two private
129-line copies are consolidated. First-only precedence, repeated lists,
signed 64-bit stops and backspace/CR use the measured GNU byte behavior.

## Development evidence

- Sort package tests pass 16/16 on each backend. Each backend also matches 52
  fixed GNU requests and passes two separate existing-output rejection checks.
  Three real pipe requests and a package reader test check seed consumption.
  Root integration adds an existing hard-link/mode fixture regression for
  ordinary output, using the established file observer and no new harness.
- The numeric/quoting/fmt packages pass 15/15 on each backend, with release
  builds. Frozen Linux amd64 comparisons retain 44 complete stream/status
  matches and four known argv0-only diagnostic differences per backend. The
  emulator overwrites argv0 even with GNU env; raw streams remain available.
  Those four public cases require their precise main diagnostic and state the
  path reason. The actual Linux CI oracle supplies independent evidence.
- Fmt also matches 52 actual native GNU C-profile requests, including adjacent
  prefix, tab, hanging-indent and EOF cases. The public corpus keeps a smaller
  selection with distinct behavior rather than all overlapping probes.
- Expand/unexpand each pass six package tests per backend. Forty-one actual
  GNU requests match complete stdout/stderr/status on both backends. Root
  integration additionally checks the shared parser/cursor calls.
