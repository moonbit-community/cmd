## Local acceptance

Registry queries confirmed that core and all 78 selected command coordinates
are the latest non-yanked versions. Exact-version MoonX execution inherited
`MOON_HOME="$HOME/.moon-accounts/cli"` on macOS. The full 2,135-case run completed:

| Result | Cases |
| --- | ---: |
| Semantic pass | 1,875 |
| Availability observation | 186 |
| Documented boundary verified | 52 |
| Platform skip | 22 |
| Failure or infrastructure error | 0 |

All seven changed commands have successful nonmetadata observations: column
16, csplit 41, diff 48, rev 8, sort 85, split 51 and tac 49. The complete
selection covers functionality beyond metadata/availability for 75 commands.
Ten additional checks passed for find, test and yes, covering name/type/depth
filtering, true/false/error statuses, file predicates and closed-pipe output.
Together these runs exercise actual functionality for all 78 commands.
There were no unknown case IDs or coordinate mismatches.

No functional failure or README/help behavior discrepancy was observed within
this local selection. The support record still called completed releases
unpublished candidates and described rev output without its 64 KiB buffering;
those documentation statements are corrected. No command implementation or
dependency declaration changed during publication or acceptance.

The existing boundaries remain explicit: nonzero percentage sort budgets
reject, rev uses its ASCII/NUL C profile, tac regex retains whole-input matcher
storage, and diff retains complete inputs. Platform skips are not passing
cross-platform evidence. This consumer run does not claim complete GNU parity
or completion of the formal performance work.

Full reports are retained in `test-reports/moonx-r-latest-all-20261025/`:
`summary.md`, `summary.jsonl`, `run-metadata.json`, `acceptance-summary.md`,
`acceptance-summary.json` and `functional-extra.json`. The acceptance summary
describes the main run; the separate supplemental results complete its three
missing functional observations. Publication logs are in
`test-reports/r-release-20261025/`.

Reproduce the complete local selection from the repository root:

```sh
MOON_HOME="$HOME/.moon-accounts/cli" \
  ./_build/native/release/build/mooxCLI/cmd-tests/release_runner/release_runner.exe \
  --manifest tests/release_runner/current/latest.json --suite smoke --jobs 1 \
  --timeout-ms 120000 --report-dir test-reports/moonx-r-latest-rerun
```
