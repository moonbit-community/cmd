# P0 修复与发布验证基线

Date: 2026-09-06

## 修复内容

- `seq FIRST LAST` 现在根据操作数方向选择单位步长，二操作数降序与 GNU
  行为一致。
- `echo`、`false`、`seq`、`sleep`、`true` 的版本输出改为引用包内版本常量。
- `sh` 将 `ShellError` 显式转换为稳定的公开诊断，不再泄漏内部类型名。
- `jqlog` help 和 parser error 输出统一保证末尾换行。

受影响命令的工作区版本升级到 `0.1.5`，待发布并完成 Wasm 资产构建；已发布
的 `0.1.4` 不覆盖。

## 验证

- `moon check --target all --deny-warn`：通过。
- `moon test --target all`：Native 103、Wasm 91，通过。
- 现有 Native compat runner：通过。
- `seq 3 1`：输出 `3\n2\n1\n`，状态 0。
- `sh -c 'arr=(one two)'`：状态 2，诊断不含 `ShellError` 或
  `cli/core/shell`。
- `jqlog --help`：最后一个字节为换行。
- `jqlog --bad`：状态 2，parser error 的 stderr 最后且仅有一个换行。

## 后续

发布 `0.1.5` 资产后，运行纯 MoonBit `tests/release_runner` 的 smoke 和
pinned-oracle differential，并据报告更新能力矩阵。
