# P0 fixes and release validation baseline

Date: 2026-09-06
Language revision: 2026-10-11; historical results retained.

## Changes recorded at the time

- `seq FIRST LAST` selected a unit step from operand direction. The original report described descending two-operand output as GNU-compatible. That interpretation was subsequently corrected: GNU's default step is +1. This historical observation is not the current support contract.
- Version output for `echo`, `false`, `seq`, `sleep` and `true` references each package's version constant.
- `sh` converts `ShellError` into a stable public diagnostic without leaking the internal type name.
- `jqlog` help and parser diagnostics end with a newline.

Affected workspace commands moved to 0.1.5, pending publication and Wasm asset builds. Published 0.1.4 versions were not overwritten.

## Validation

- `moon check --target all --deny-warn`: passed.
- `moon test --target all`: Native 103 and Wasm 91 passed.
- Existing Native compat runner: passed.
- `seq 3 1`: observed `3\n2\n1\n`, status 0; see the historical correction above.
- `sh -c 'arr=(one two)'`: status 2; diagnostic excludes `ShellError` and `cli/core/shell`.
- `jqlog --help`: final byte is a newline.
- `jqlog --bad`: status 2; parser stderr has exactly one trailing newline.
