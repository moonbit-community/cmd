## P1: HTTP

`curl` and `wget` share repository-owned HTTP/HTTPS fixtures and a common
network adapter. The delivered profile covers methods, request bodies,
uploads, output naming, redirect limits, retry classification, connect/total/
idle timeouts, HTTP CONNECT proxy selection, no-proxy behavior, and explicit
TLS verification controls. FTP/SFTP/SMTP, auth/cookie/config state, HTTP/2,
recursive Wget mirroring, and exact progress bytes remain outside the profile.

## P2-P3: text pipelines

The text tools now have deterministic C-locale byte behavior for context and
binary policies, NUL records, field/key controls, numeric/month/version forms,
file-list totals, and status-check modes. `sort -R` and `tail -F` remain
verified rejections because the repository has no deterministic random seed or
portable path-reopen contract.

## P4: find/xargs

`find` gained bounded metadata predicates, `-prune`, `-depth`, safe postorder
delete, and one-child or deterministic batched execution. `xargs` gained NUL
and quoted tokenization, replacement, line/size limits, EOF strings,
`--show-limits`, and bounded `-P`. Child launches remain direct and policy
visible; ambient shells and unbounded process control are not accepted.

## P5: shell

The MoonBit interpreter covers command substitution, redirections and
heredocs, conditionals, `case`, loops, functions/`return`, grouping/subshells,
parameter length/shift, and `set -e/-u`. Bash-only syntax, interactive job
control, arrays, startup files, and host-shell delegation remain rejected.
