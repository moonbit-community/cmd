## P6-P7

`jq` supports the measured CLI modes for sorting, slurping, raw/join output,
exit status, argument bindings, indentation, and the imported evaluator slice.
It is not a complete jq 1.8.2 language/modules/diagnostic claim. `make` covers
conditionals, includes, pattern rules, automatic variables, what-if behavior,
and bounded recipe execution. `xxd` covers include output and addressed reverse
patching; jobserver parallelism and negative/end-relative seeks remain closed.

## P8 filesystem subset

The pure MoonBit implementation uses only public `moonbitlang/async/fs`
operations and repository code. `core/fsops` and `core/platform` expose file
kind, regular-file size, access checks, atime/mtime/ctime reads, nanosecond
comparison, age buckets, symbolic-link creation, update/interactive/backup
decisions, and preflighted `-H/-L/-P` traversal.

The command layer applies that subset to `test`, `find`, `ls`, `cp`, `mv`,
`chmod`, `ln`, and `touch`. Unsupported setters and observations fail closed:
ownership and inode data, arbitrary timestamp setters, metadata-preserving
copy, hard links, `readlink`, special-file creation, and reliable EXDEV
classification are not simulated.
