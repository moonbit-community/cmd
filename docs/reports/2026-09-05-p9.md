# P9 compatibility closure report

- Delivery date: 2026-09-05
- Commits: `14afdc5`, `58c8860`, `27db23e`
- Status: complete

## Scope

P9 closed the remaining low-risk command-local gaps without expanding the
runtime boundary. The delivered families were base64; basename/dirname;
cmp/comm/cat; cut/paste/nl/join; printf/seq/echo; pwd/printenv; sha256sum;
rmdir/rm/mkdir/tee; sleep/true/false; and the fixed C-locale byte profile of
`tr`.

The manifest gained 35 P9 cases. They cover successful output, invalid values,
status precedence, NUL records, repeated stdin operands, malformed delimiters,
GNU diagnostics where stable, checksum verification controls, failure ordering,
and no-side-effect rejection. The runner reuses one pre-built artifact root for
the whole group.

## Oracle corrections

The first remote oracle run exposed four real edge mismatches. They were fixed
and rerun:

- `cmp` uses the pinned diffutils `char` diagnostic wording;
- `tr` emits the exact ambiguous-octal warning for `\400`;
- `paste` treats `\0` as an empty delimiter and emits the GNU serial empty-input
  record;
- `pwd` falls back correctly for an invalid logical path on Windows.

The corrected implementation passed the pinned upstream oracle and the full
Native macOS/Windows matrix.

## Wasm verification boundary

The unified Wasm policy suite passed against the pre-built release root. A
fresh isolated policy root was also used to invoke 24 direct P9 option/status
smoke checks against the actual `.wasm` files, including binary/NUL paths,
filesystem mutation, checksum verification, and `tr` byte translation. This
smoke confirms artifact execution and the selected paths; it does not promote
every P9 option to a full Wasm differential claim. The support matrix remains
the authority for that distinction.

## Documentation result

Every affected command README, the support record, runner manifest, and the
relevant ADR evidence were updated together. The permanent boundaries remain
explicit: no locale data beyond C bytes, no host delegation, no fabricated
filesystem capabilities, and no full GNU claim from a help line or smoke test.
