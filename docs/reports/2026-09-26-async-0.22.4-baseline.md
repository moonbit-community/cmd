## Public API decisions

The 0.22.4 baseline keeps the implementation plan pure MoonBit. Public fs
APIs expose kinds, size, timestamps, directory traversal, creation modes and
chmod, but do not expose file identity, mode reads, readlink, hard links,
owner/group metadata or handle-based truncation. Public process APIs still do
not provide exec, process groups, PTY/isatty, terminal attributes or arbitrary
signal delivery. Internal runtime structures are not treated as project APIs.

The streaming Reader/Writer and gzip interfaces are available for future pure
MoonBit implementations. Unsupported behavior remains an explicit boundary
with a rejection regression and an unlock condition in
`docs/async-upstream-gaps.md`.
