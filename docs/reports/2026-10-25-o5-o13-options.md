# Selected O5–O13 command options

Date: 2026-10-25. Unpublished workspace implementation.

This change completes the selected option families in the execution plan for
split, csplit, rev, tac, od, hexdump, cmp, strings, xxd, cksum and the four
digest commands, realpath, mktemp, mkdir, rm, ls, tree, env, xargs, tail and tee.
The command READMEs, help, shared catalog and current compatibility/ADR records
describe each supported profile and remaining public-API boundary.

Split uses incremental byte/line and round-robin paths, with an owned spool for
total-dependent distribution. Csplit compiles suffix formats once. The byte
matcher adds Emacs syntax and a rightmost-span adapter for tac. Od and hexdump
share exact floating-point conversion and compiled format state. Xxd processes
fixed-size blocks and uses actual random-access writes for newly created reverse
output. The checksum commands share one incremental digest/checking engine,
including the selected SHA2/SHA3/BLAKE2b/SM3 profiles.

Filesystem options use released public APIs for lexical paths, exclusive
temporary creation, symbolic modes and prompting. Unsupported physical-link,
mode or existing-output identity operations remain explicit rejection cases.
Ls applies quoting before layout. Tree uses iterative traversal, postorder totals
and text/JSON/HTML rendering. Directory-size support follows the actual platform
API: Linux supplies size; macOS reports its supported refusal. No fabricated
directory sizes are used. HTML rendering has its documented project profile.

Env parses `-S` itself. Xargs keeps prompting separate from argument stdin.
Tail supports NUL-delimited records. Tee handles each explicit output-error mode
independently; default SIGPIPE restoration remains a runtime boundary.

Validation compares complete streams, status and relevant filesystem effects.
The ordinary contracts retain fixed upstream observations. Random mktemp names
are checked through their reported-path/type/empty/private-mode relationships;
raw names remain in the run evidence. Tee tests close a real stdout pipe and
check later file sinks. Env/xargs use the same small pure-MoonBit child under the
workspace command and upstream command, preserving argument boundaries. These
fixtures do not use a host shell as the command implementation.

labels, trailing-space filenames and available CONIN$ input. Corrections keep
those platform effects explicit. The mktemp executor regression selects the
actual platform profile, including the absence of a POSIX-mode claim on Windows.
