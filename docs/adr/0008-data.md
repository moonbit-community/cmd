# ADR-0008: Bounded JSON Modes

Status: Accepted  
Date: 2026-09-05

## Context

The imported JSON evaluator provides valuable filters, but its surface and
diagnostics are not the same as a complete system `jq` release. `jqlog` follows
its own imported contract.

## Decision

Publish deterministic `jq` CLI modes (`-S`, `-j`, `-s`, `-R`, `-e`, argument
bindings, indentation) only alongside the evaluator slice that is directly
observed. Measure `jqlog` against its imported contract, not system `jq`.

## Consequences

Users get a useful JSON CLI without a false jq 1.8.2 claim. Modules, streaming,
full diagnostics, and untested language forms remain outside the support row.

## Evidence

The P6 manifest includes positive sorting/slurp/status cases and invalid indent
and argument cases.

## Revisit when

The evaluator has an independent versioned oracle suite for the remaining jq
language and diagnostic surface.
