# ADR-0008: Data and Language Algorithms

Status: Accepted
Date: 2026-09-05
Updated: 2026-10-30

## Decision

Use released public dependencies where their semantics fit. Keep narrow pure
MoonBit adapters where they do not. Algorithm packages own data and execution;
command adapters own options, records, diagnostics and exit behavior. Do not
patch dependency caches, add FFI or delegate to host implementations.

Different regex dialects, numeric representations and failure prefixes are
intentional contracts. Similar source structure is insufficient reason to
replace them with one generic engine. Shared ownership is recorded in
[ADR-0003](0003-streams.md#package-ownership).

## Regex and search

Core bytere parses C-byte BRE/ERE once. Ordered Thompson threads handle ordinary
matching; span searches omit capture tags when no backreference observes them.
Capture searches preserve selected original bytes. Backreferences retain full
states on an explicit stack and can consume exponential resources; no hidden
step cap changes their language. GNU repeated-nullable-capture selection and
register restoration differ from Boolean candidate pruning and must stay distinct.

Grep scans input incrementally, retaining cross-chunk records and requested
context. Binary detection on incoming bytes preserves earlier text before a
later NUL. Quiet/file-summary modes may stop early. Sed compiles groups/labels
before input, then executes its PC, hold space, substitution state and append
queue. Lazy final-line inspection preserves partial errors. Script-controlled
spaces and longest records can grow; sed in-place replacement remains a
filesystem boundary.

Rg keeps its pinned private regex, Unicode/encoding, glob/ignore, searcher and
printer components and original notices. Generated tables are frozen source
data; regeneration needs reviewed pure MoonBit tooling and pinned-input checks.
Its leftmost-first semantics do not replace core BRE/ERE/Emacs behavior.
Indexing, PCRE2 and an effective DFA byte-budget remain explicit unsupported
features; streaming/no-op option syntax does not claim mmap or parallel search.

Effective -z/--search-zip rejects before input. The discarded construction is
recoverable at `c048555482855b36eb7c5b62f688cd7bee201395:experiments/rg-compression`.
Re-enable only after all eight formats and streaming, concatenation, corruption,
truncation, partial-output and early-stop CLI cases pass on supported Wasm hosts.

## Numeric and binary formats

Seq and printf share exact BigInt-based numeric formatting under the fixed GNU
Linux amd64 Extended80 profile on every host. Parsing, ties-to-even, subnormals,
range and first+i*step rounding retain that representation. Hexadecimal output
uses the selected GNU libc form; printf preserves NaN signs and requested flags.
Do not infer a host long-double ABI or narrow through Float64.

Seq -f accepts one supported floating conversion; its default/integer path is
separate. Printf %q uses C-byte shell escaping and rejects flags/width/precision
after preserving earlier output. Format reuse and missing arguments remain
distinct. Od/hexdump reuse the numeric package for selected binary16, bfloat16,
binary32/64, x87 and binary128 layouts, endianness and special values. This is
a fixed ABI profile, not arbitrary native representation or locale parity.

Checksum algorithms are incremental. Public digest implementations are reused;
missing variants remain pure MoonBit with standard vectors and chunk/padding
tests. Shared CLI records preserve tagged/untagged forms, escapes, lengths,
base64/raw output and mismatch/read-error distinctions. Binary/text flags select
markers under the C-byte profile; they do not imply Windows text translation.
Base32 follows RFC 4648 padding and decoded-prefix error rules.

## JSON and time

Frame consecutive top-level JSON values and preserve earlier output before a
later parse error. Jq's -s/-R/-n/-e modes and jqlog's JSONL profile remain distinct.
Use moonjq public lexical AST bindings for --arg/--argjson. A small adapter
lowers read string slices through Unicode scalar arrays, including nested
bodies; assignment/path locations remain unchanged. Textual source replacement
or vendoring the evaluator is not justified by this gap.

Explicit jq -C emits ANSI and -M suppresses it, with -M winning when both are
present. Raw strings remain raw. Automatic color requires terminal detection;
explicit formatting does not. Remove the slice adapter only when a released
evaluator passes nested/open/negative/Unicode, error and assignment regressions.

The 2026-10-30 benchmark repair exposed a separate moonjq 0.2.0 grouping-order
gap. For mixed null/false/true `.active` keys, `group_by(.active) | map(length)`
returns encounter-ordered groups instead of jq key order. The 1/8 MiB canonical
rows retained exact comparison and failed in that earlier execution; no output
normalization was used. Lift the limitation only with a released
evaluator or a public-AST adaptation that preserves once-only key evaluation,
member order, errors and lexical bindings, plus focused mixed-key regressions.

Date/diff share checked TZif v1-v4 parsing, 64-bit transitions and POSIX future
rules with x/time calendar arithmetic. Honor TZ/TZDIR/localtime and -u; retain
zone abbreviations separately from zero-offset UTC canonicalization. Parse
inline POSIX rules before Windows path probes when their syntax is invalid in
filenames; explicit file paths retain real filesystem errors.

Reject malformed/missing zones, leap-second records, unsupported transition
rules and ambiguous/gap local input rather than inventing timestamps. ISO/epoch
input retains nanoseconds; the public current clock has millisecond precision.
Relative parsing, more directives and locale support are project work; changing
the clock requires a setter API. Replace the checked adapter only when public
parsing and offset metadata pass the same long-range/DST fixtures.

## Diff and gzip

Diff separates comparison keys from original records. Case/whitespace options
and blank-only suppression do not delete blank records before comparison.
Strip-trailing-CR explicitly changes both comparison and displayed records.
Bidirectional frontiers and an explicit subdivision stack use O(N+M) auxiliary
reconstruction storage; inputs, keys and results remain additional allocations.
Keep repeated-record hunk-choice tests as well as minimum-edit properties.

Gzip encoding uses 32 KiB LZ history, 3-258-byte matches, canonical Huffman
trees and complete stored/fixed/dynamic cost selection over 64 KiB chunks.
Levels 1-9 vary effort; last level wins, and decoding/testing ignores levels.
Compare decoded bytes and failures, not exact upstream compressed bytes.

Reader decoding shares a cursor across headers, blocks, trailers and members,
with 64 KiB input/output and a 32 KiB history retained in the output ring.
Complete short codes before refilling. Preserve decoded prefixes on truncated
trailers, CRC or read failure, and never replay a failed write during cleanup.
Bytes callers still retain their input. A public Decoder that loses those
effects is not an equivalent replacement. Force/pass-through and listing are
project work; named replacement and metadata restoration remain ADR-0004 limits.

## Verification and reconsideration

The 2026-10-30 unreleased workspace repair captures each complete grouping or
sorting key stream once through the public moonjq AST. Grouping canonicalizes
object entry order and safe numeric spellings, groups by full encoded keys,
then orders groups by their original semantic key streams. Sorting decorates
keys with encounter indexes for stable ties. Original values remain intact;
generated bindings are introduced only after the original filter evaluation.
Tests include deep keys beyond the dependency debug formatter limit, empty and
multiple key streams, lexical bindings and thousands of stable ties. Numeric
ordering at or above 2^53 still uses the dependency comparator; remove that
limitation only after an exact released numeric comparator and CLI vectors.
Published package coordinates retain their prior behavior until a separate
versioned release through `moon publish`.

Use exact package vectors and command byte/status/effect assertions, with the
immutable references in [upstream-baselines.md](../upstream-baselines.md).
Current dependency coordinates come from [core/moon.mod](../../core/moon.mod);
published coordinates come from the release manifest. Historical Native tests
and local timings retain their original scope; current delivery follows
[ADR-0001](0001-evidence.md).
