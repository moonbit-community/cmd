# ADR-0008: Streaming JSON Inputs and Lexical Bindings

Status: Accepted
Date: 2026-09-05
Updated: 2026-10-11
Revision: Upgrade released moonjq, adapt scalar string slicing, and share checked TZif/POSIX conversion between date and diff.

## Target and decision

Frame consecutive top-level JSON values, retain earlier output before later parse errors, and implement -s/-R/-n/-e CLI semantics. Use moonjq 0.2.0 public lexical AST bindings for --arg/--argjson, preserving strings/interpolation and allowing inner shadowing. jqlog retains its separate JSONL contract.

Released moonjq 0.2.0 repairs tostring/tojson but still returns null for string
slices. A shared public-AST adapter lowers read slices through Unicode scalar
arrays, recursively including filter/function bodies, and raises on invalid
input types. Assignment/path operands retain their location AST. Do not patch
dependency caches, substitute query source text, vendor the entire evaluator,
or invoke host jq. Cost: maintain an AST adapter tied to the released enum;
remove it when an upstream release passes the nested/open/negative/Unicode,
optional/error and assignment regressions. No full jq grammar claim follows
from fixing these operations.

Implement explicit `-C` ANSI output and `-M` suppression in MoonBit, including
compact/pretty output, nested values and `JQ_COLORS` parsing. When both options
are present, `-M` wins as in jq 1.8.2. Raw string output remains raw. Automatic
terminal coloring remains unavailable until a released public isatty API can
distinguish terminals reliably; character-device classification is insufficient.

## Alternatives and compatibility cost

The 0.1.0 command candidates share pure MoonBit `bytere`, `checksum`, and
`gzipops` packages in core 0.3.0. MD5/SHA-1/SHA-512 update incrementally, including
padding/block-boundary regressions. Byte views retain NUL and malformed UTF-8;
regex matching uses an explicit C-byte profile with unsupported constructs
rejected. Full locale/regex grammar remains project work, not an async blocker.

Use a pure RFC 1951 inflater plus the public async Encoder. A public Decoder
adapter alone could not preserve output before truncated trailers. Stored,
fixed and dynamic blocks, overlapping distances and 32 KiB wraparound have
independent fixtures; a GNU gzip 1.14 script checks both directions. The cost is
maintaining a decoder and buffering compressed input; compression currently
emits valid stored blocks and rejects compression-level options. Reject private
ReaderBuffer imports, FFI and host gzip fallback. Replace the inflater only
after released public APIs satisfy optional headers, multiple members and
partial-output error regressions. See [API feedback](../async-upstream-gaps.md).

Reject a single-document assumption for ordinary jq stdin, textual variable replacement and calling input framing an async blocker. The evaluator's bounded expression surface is not complete jq 1.8.2 modules/streaming/diagnostics.

Reject silently accepting `-C` with plain output, and do not classify explicit
color formatting as an async limitation. Keeping automatic color disabled costs
TTY convenience while preserving deterministic redirected output. Explicit
flags remain available on both backends without adding FFI or delegating to jq.

## Versions and evidence

Baseline: async 0.22.4, x 0.5.5, moonjq 0.1.2; MoonBit 2026-09-20.
The async 0.22.4 refresh does not change the JSON evaluator boundary. It
does enable the independently implemented `base32` command: RFC 4648 uppercase
encoding/decoding, GNU-compatible padding handling and progressive prefix output,
`-d`, `-i` and `-w` are implemented in pure MoonBit with byte-level tests.
As in the pinned GNU implementation, non-zero unused tail bits are accepted;
nonstandard alphabets and locale diagnostics remain outside the support claim.
The `expand` and `unexpand` profiles use byte columns with explicit positive,
ascending stops. This keeps tab conversion independent of terminal width and
locale databases; malformed stops reject before input side effects. Multibyte
display-width behavior remains outside the support claim.
jq tests and unified command contracts cover consecutive values, slurp, raw
slurp, null input, false status and shadowing. Exact-byte color comparisons use
the official jq 1.8.2 executable and cover compact/pretty/indent/key-order output,
raw strings, `-CM`/`-MC` and valid/partial/invalid palettes. Full dependency
resolution uses moonjq 0.1.2 with x 0.5.5 and async 0.22.4.
Historical results remain in [the audit](../reports/2026-09-19-command-fidelity-audit.md).
Candidate runtime results are recorded separately from published versions.

## Migrated algorithm profiles

For these decisions the target is the named upstream command, using released
public dependencies only. Versions: MoonBit 2026-09-20, async 0.22.4,
x 0.5.5; core 0.3.0 for the second batch and 0.4.0 for the P2 batch.
Verification is the per-command JSON/package tests plus the immutable
[second-batch](../reports/2026-10-11-release-0.1.0/README.md) and
[P2](../reports/2026-10-11-p2-release-0.1.0/README.md) release reports;
the selected cases do not certify omitted upstream operations.

| Commands | Choice and reason | Alternative rejected / compatibility cost | Evidence and unlock condition |
| --- | --- | --- | --- |
| base32, cksum | RFC 4648 Base32 with GNU padding/error-prefix rules; POSIX CRC-32 and length for cksum. Small pure byte algorithms need no native library. | No host encoder or conflating POSIX CRC with other CRC variants. GNU cksum algorithm selection/check/tag modes remain project work; nonstandard Base32 alphabets are outside this command's baseline. | `base32.json`, `cksum.json`, package tests and 0.1.1 release evidence. Extend cksum only with exact selected-algorithm/check-record cases, reusing public digest code. |
| md5sum, sha1sum, sha512sum | Reuse public x/crypto incremental hashes through shared GNU checksum record handling. Bounded-memory hashing preserves bytes and operand order. | No duplicate digest algorithm/FFI. Tagged formats and Windows text translation remain absent; `-b/-t` currently change the record marker, not input bytes. | `core/checksum` tests and the three command contracts. Add tagged parsing/escaping and independent padding/large-stream vectors; Windows text mode requires its own exact upstream cases. |
| sed, expr | Share a pure C-byte BRE/ERE implementation; sed has addresses/substitutions and replacement captures, expr has BigInt arithmetic and short-circuit evaluation. Unsupported regex syntax rejects explicitly. | Do not rewrite source text, forward programs to host tools or approximate backreferences. sed hold space/branches/groups/multiline commands and expr extended regex/locale remain project work. sed `-i` additionally requires correct replacement metadata (ADR-0004). | `core/bytere`, sed/expr package tests and JSON contracts. Add GNU regex selection/capture, execution-state and partial-output cases before extending syntax; never classify parsing as async-blocked. |
| diff | Buffer byte lines and compute an edit trace, exposing normal/unified/context output and 0/1/2 status. | gzip, gunzip, zcat | Share one gzip engine and pure inflater; public Encoder currently writes stored blocks. | date, diff timezone headers | Public fs reads plus a shared pure MoonBit TZif v1–v4 decoder, checked 64-bit transitions and POSIX future rules; x/time supplies calendar arithmetic. Reject malformed/missing files, leap-second records, DST rules without explicit transitions, and ambiguous/gap local input instead of substituting timestamps. ISO input/epoch fractions retain nanoseconds; now has public clock millisecond precision. Unknown GNU-supported format fields/modifiers reject; relative parsing/extra fields remain project work. | Coreutils 9.11, 35 timezone calls including 2038/2050/DST and checked-decoder tests; portable TZif fixtures in date.json, diff header contracts. Remove adapter only when released public parser/offset metadata pass the same tests. Open folded local times, leap scales, locale and additional directives only with corresponding upstream oracles; clock mutation still requires a setter API. |

## Revisit when

Adopt evaluator features through public APIs only after exact input/output/status
regressions pass. Reopen automatic color when released terminal detection has
Native/Wasm tests covering TTY and redirected streams separately.
