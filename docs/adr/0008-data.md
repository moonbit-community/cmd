# ADR-0008: Data and Language Algorithms

Status: Accepted
Date: 2026-09-05
Updated: 2026-11-01

## Decision

Use released public dependencies where their semantics fit, with narrow pure
MoonBit adapters elsewhere. Algorithm packages own execution; command adapters
own options, records, diagnostics and status. Do not patch dependency caches,
add FFI or delegate to host implementations.

Regex dialects, numeric representations and failure prefixes are distinct
contracts. Similar loops do not justify one generic engine. Keep package
ownership in [ADR-0003](0003-streams.md#package-ownership) and algorithm details
in [the performance guide](../performance/README.md).

## Search and codecs

Core bytere preserves C-byte BRE/ERE, ordered Thompson matching and original
capture bytes. Capture elision is valid only when backreferences cannot observe
it. Backreferences use explicit full states and may take exponential resources;
a hidden step cap would change the language. GNU repeated-nullable-capture
selection differs from Boolean pruning.

Grep retains incremental records/context and earlier text before later binary
detection. Sed compiles scripts before input and preserves PC, hold space,
substitution state, append queues and lazy final-line errors. Long records and
script-controlled spaces may grow; in-place replacement remains ADR-0004.

Rg retains pinned regex, Unicode/encoding, glob/ignore and printer components
with their notices. Its leftmost-first semantics do not replace BRE/ERE/Emacs.
Frozen generated tables need reviewed pure MoonBit regeneration and pinned
inputs. PCRE2, indexing and effective DFA byte budgets remain unsupported;
accepted no-op syntax does not promise mmap or parallel execution.
Effective --search-zip rejects before input. Re-enable only with all eight
formats and streaming, concatenation, corruption, truncation, partial-output
and early-stop tests on supported Wasm hosts. The discarded experiment remains
at c048555482855b36eb7c5b62f688cd7bee201395:experiments/rg-compression.

Checksums use incremental public digests or pure implementations with standard
vectors. CLI record markers, escapes, lengths and error distinctions stay
separate from algorithms; binary/text markers do not imply Windows translation.
Base32 preserves RFC 4648 padding and decoded-prefix errors. Base32/base64
encoding is incremental; whole-input decode behavior remains explicit.

Gzip selects stored/fixed/dynamic costs with a 32 KiB history and 64 KiB chunks.
Levels vary encoding effort; decoding ignores them. Reader decoding owns framing,
history and member state, preserves prefixes before CRC/trailer/read failures
and never replays failed writes. Compare decoded bytes, not exact compressed
output. Metadata replacement stays in ADR-0004. See
[search](../performance/search.md) and [codecs](../performance/codecs.md).

## Numeric and binary profiles

Seq/printf share exact BigInt formatting under a fixed GNU Linux amd64
Extended80 profile on all hosts, including rounding, special values and
first+i*step behavior. Do not infer host long-double ABI or narrow through
Float64. Seq's one-conversion -f path stays separate from its default integer
path. Printf %q uses C-byte escaping and rejects flags/width/precision after
preserving earlier output.

Od/hexdump use selected binary16, bfloat16, binary32/64, x87 and binary128
layouts and endianness. These are fixed profiles, not arbitrary native ABI
or locale parity. Sort's exact decimal ordering is distinct from general
numeric comparison; see [ordering](../performance/ordering.md).

## JSON and time

Frame consecutive JSON values while preserving earlier output before later
parse failure. Jq modes and jqlog's JSONL profile remain distinct. Adapt moonjq's
public lexical AST for bindings, Unicode-scalar read slices and stable grouping/
sorting. Do not reparse textual replacements or vendor the evaluator.

Grouping/sorting evaluates each complete key stream once, preserves original
values and lexical bindings, canonicalizes deep group keys, and orders by
semantic keys with stable ties. Numeric ordering at or above 2^53 still uses
the dependency comparator. Remove adapters only after released equivalents pass
nested/empty/multiple-key, Unicode, assignment, error and stable-tie regressions.
Current workspace repairs do not rewrite frozen published behavior.

Explicit jq -C emits ANSI; -M wins and raw strings stay raw. Automatic color
needs terminal detection. Slice assignment/path locations remain unchanged.

Date/diff use checked TZif v1-v4, 64-bit transitions and POSIX future rules.
Honor TZ/TZDIR/localtime and -u; distinguish abbreviations from canonical UTC.
Parse inline POSIX rules before invalid Windows filename probes. Reject
malformed/missing zones, leap-second records, unsupported rules and ambiguous/
gap local times. Input retains nanoseconds; the current clock has millisecond
precision. Locale/directive expansion is project work; clock mutation needs
a public setter. Replace the adapter only with equivalent long-range/DST tests.

## Verification and reconsideration

Diff preserves original records separately from comparison keys; blank-only
suppression does not pre-delete blank records. Strip-trailing-CR affects both
comparison and display. Minimum-edit properties and repeated-record hunk choices
are separate regressions; auxiliary linear reconstruction space is not a total
memory bound. Details are in [ordering](../performance/ordering.md).

Use exact vectors and byte/status/effect assertions with
[pinned references](../upstream-baselines.md). Keep current dependency
coordinates in [core/moon.mod](../../core/moon.mod), published expectations in
the release manifest, and delivery gates in [ADR-0001](0001-evidence.md).
Historical implementation detail remains available in the
[pre-consolidation ADR](https://github.com/moonbit-community/cmd/blob/c4ea7795b0eb6e6fd6d0dffa0e7709809569bbb1/docs/adr/0008-data.md).
